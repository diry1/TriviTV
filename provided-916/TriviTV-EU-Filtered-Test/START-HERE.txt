TriviTV — EU-filtered Ukrainian test build

916 questions playable with Ukrainian + Europe + all categories.
English + Europe has 928 questions. These are draft screening candidates.
All 36,614 acquired Ukrainian translations remain archived in the server data,
but held/excluded/unassessed records cannot enter Europe games.
This is not the previous 36,614-question unfiltered milestone ZIP.

1. Extract the ENTIRE ZIP.
2. Install Node.js 24+ on the PC if needed: https://nodejs.org
3. Stop the old TriviTV server terminal before starting this version (Ctrl+C).
4. Double-click Server/Start TriviTV.bat on Windows.
   macOS/Linux: open a terminal in Server and run: node start-eu-test.js
5. Keep that terminal open during play.
6. Install the included Ukrainian test APK on the TV if it is not installed.
   If already installed, reuse it. The APK is unchanged; filtering is in the server.
7. Connect the TV and PC to the same trusted local network.
8. Enter the PC's LAN address in the app, e.g. http://192.168.1.10:3000.
   Do not use localhost on the TV. Allow Node.js on private networks if prompted.
9. Keep Українська and Європа selected. With all categories, setup must show:
   Доступно запитань із цими налаштуваннями: 916.
   If not, check that the OLD server was stopped and the browser/TV page reloaded.

Phones use the same PC address and join using the room code.
Small categories give shorter games: Television 1, Video Games 2, Music 3.
There is no fallback to held/excluded questions. Switching to US uses the previous
US regional pool, so stay on Europe when testing the 916-question pool.

No API key, paid API call, npm install or resumed translation is needed to play.
No source questions were deleted. Most withheld records are not yet semantically
assessed, rather than definitively rejected. See Filtering report/summary.json and
Server/docs/eu-filtering.md for counts, scope, evidence and regeneration steps.
Outdated replacements remain deferred. Physical TV testing is still required.
